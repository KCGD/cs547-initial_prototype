# Stevens Scheduling Guide
Say goodbye to your time management worries!

# Building & Running
## Dependencies / runtime
Have Node.js and NPM installed.
A guide is available [here](https://nodejs.org/en/download)

This project was build on Node.js `v26.13.1` and npm `v11.20.0`.
While it is reccomended to match this version exactly, any Node.js
more recent than or equal to `v22.xx.x` will suffice.

## Code
To get started clone the code from this repository.

```sh
git clone https://github.com/KCGD/cs547-initial_prototype.git
cd cs547-initial_prototype
```

After the code is cloned and you are in the project directory,
install the required packages with:
```sh
npm i
```

## Running the code
Once dependencies and packages are all present, you can
run the code via
```sh
npm run dev
```

And access the web-app via the link generated in your console.

# Device Emulation
If accessing this webapp on the desktop, it is encouraged
to enable your web browser's mobile device emulation
by opening the developer tools (Ctrl+Shift+i) and clicking
the mobile phone icon in the top right (near the X).

While the UI does work on desktop, it is mainly designed for
mobile browsers.
